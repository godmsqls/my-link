# my-link 🔗

> Next.js와 Tailwind CSS로 제작한 감각적인 반응형 개인 프로필 및 링크 모음 웹 애플리케이션입니다.

## ✨ 주요 특징 (Features)

- 🎨 **모던 & 미니멀 디자인**: 깔끔한 글래스모피즘(Glassmorphism) 스타일과 세련된 그라디언트 UI
- 🌓 **다크 모드 지원**: 시스템 설정에 맞춘 자연스러운 라이트/다크 테마 지원
- 📱 **완벽한 반응형(Responsive)**: 모바일과 데스크톱 어디서든 최적화된 레이아웃 제공
- ⚡ **빠른 성능**: Next.js App Router와 최신 Tailwind CSS v4를 활용한 가벼운 렌더링

---

## 🛠 기술 스택 (Tech Stack)

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## 🚀 시작하기 (Getting Started)

### 1. 레포지토리 클론 및 종속성 설치

```bash
git clone https://github.com/godmsqls/my-link.git
cd my-link
npm install
```

### 2. 개발 서버 실행

```bash
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)으로 접속하여 결과를 확인합니다.

### 3. 빌드 및 배포

```bash
npm run build
npm run start
```
